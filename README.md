# Lotus Docs

В Lotus Docs я собрал инструменты для подготовки статей, конвертации файлов и работы с изображениями. Все файлы обрабатываются локально в браузере и остаются на устройстве пользователя.

Адрес проекта: [lotusdocs.ru](https://lotusdocs.ru).

## Возможности

- **Подготовка статей из DOCX.** Очистка HTML, сохранение заголовков, списков, таблиц и ссылок. Экспорт в HTML, Markdown и обычный текст.
- **Изображения для CMS.** В тексте остаются маркеры `<!-- img1 -->`, `<!-- img2 -->` и далее. Изображения можно скачать отдельно или вместе со статьёй в ZIP для размещения в Битриксе и других системах управления сайтом.
- **Конвертация файлов.** Автоматическое определение исходного формата и выбор доступных направлений: изображения, DOCX → HTML/PDF, CSV → JSON, XLSX → CSV.
- **Сжатие изображений.** Три режима для JPEG и WebP, обработка PNG, сохранение размеров в пикселях и отображение экономии места.
- **Векторизация.** Преобразование растровых изображений в SVG с настройкой цветов, детализации и сглаживания.

Для интерфейса я выбрал чёрно-белое оформление, адаптивную вёрстку и векторные анимации. Сервис работает без регистрации.

## Технологии

React, Vite, Mammoth, JSZip, pdfmake, SheetJS, ImageTracer и UTIF. Обработка DOCX выполняется в Web Worker. Для проверки проекта используются Node.js Test Runner, Playwright и axe-core.

## Локальный запуск

```sh
npm ci
npm run dev
```

В Windows PowerShell при ограничении исполнения скриптов используйте `npm.cmd` вместо `npm`.

## Сборка и проверки

```sh
npm test
npm run test:e2e
npm run build
npm run test:build
npm run preview
```

Для браузерных тестов нужен установленный Google Chrome. Готовая сборка находится в `dist`.

## Размещение

Основной домен — `https://lotusdocs.ru`. При сборке создаются HTML-страницы всех разделов, метаданные для поиска и социальных сетей, canonical, JSON-LD, `sitemap.xml` и `robots.txt`.

На хостинге каждый раздел должен открывать свой `dist/<маршрут>/index.html`, а главная — `dist/index.html`. Для неизвестных адресов настройте HTTP 404. Адреса разделов используются без завершающего слеша.

Для размещения на другом домене задайте `VITE_SITE_URL` в `.env` по примеру `.env.example` и выполните сборку заново.
